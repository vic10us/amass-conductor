# OWASP Amass PostgreSQL Database Schema

> Generated from `github.com/owasp-amass/asset-db@v0.24.2` migration files.

## Overview

The Amass asset database implements a **normalized property graph** on top of PostgreSQL 13+. Assets are stored in dedicated typed tables, linked through a central `entity` table, with `edge` and tag tables forming the graph layer.

### Architecture

```
┌─────────────────────────────────────────────────────────────────────┐
│                        PostgreSQL Extensions                        │
│                   citext · pg_trgm · btree_gin                      │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│   ┌──────────────┐    ┌──────────────┐    ┌──────────────┐         │
│   │entity_type_lu│    │ edge_type_lu │    │ tag_type_lu  │         │
│   │  (21 types)  │    │  (5 types)   │    │  (4 types)   │         │
│   └──────┬───────┘    └──────┬───────┘    └──────┬───────┘         │
│          │                   │                   │                  │
│   ┌──────▼───────┐    ┌──────▼───────┐    ┌──────▼───────┐        │
│   │    entity     │◄──►│     edge     │    │  entity_tag  │        │
│   │  (graph node) │    │ (graph link) │    │  (node prop) │        │
│   └──────┬───────┘    └──────────────┘    └──────────────┘        │
│          │                   │                                      │
│          │            ┌──────▼───────┐                              │
│          │            │   edge_tag   │                              │
│          │            │ (edge prop)  │                              │
│          │            └──────────────┘                              │
│   ┌──────▼─────────────────────────────────────────────────┐       │
│   │              21 Asset Tables                            │       │
│   │  account · autnumrecord · autonomoussystem · ...       │       │
│   │  Each row → one entity row (via entity_upsert)         │       │
│   └─────────────────────────────────────────────────────────┘       │
└─────────────────────────────────────────────────────────────────────┘
```

### Graph Model

1. Each **asset** row (e.g., `fqdn`, `ipaddress`) is registered in the `entity` table via `entity_upsert()`, creating a graph node.
2. **Edges** connect two entities with a typed, labeled relationship. The `edge.content` JSONB column carries edge-specific data.
3. **Tags** (entity_tag, edge_tag) attach key-value properties to nodes and edges, with an additional `content` JSONB payload.
4. **Lookup tables** (`entity_type_lu`, `edge_type_lu`, `tag_type_lu`) use `smallint` IDs for compact storage.

## Relationships

### How Entities Connect

Entities are connected via the `edge` table. Each edge has:
- A **type** (`etype_id` → `edge_type_lu`) that categorizes the relationship
- A **label** (`citext`) that provides a specific name for the relationship
- A **direction**: `from_entity_id` → `to_entity_id`
- Optional **content** (JSONB) for relationship-specific data

### Edge Types and Their Semantics

| Edge Type          | Typical Usage                                          |
|--------------------|--------------------------------------------------------|
| `basicdnsrelation` | DNS record mappings (A, AAAA, CNAME, MX, NS, etc.)   |
| `portrelation`     | IP address → service on a specific port               |
| `prefdnsrelation`  | Preferred/authoritative DNS relationships             |
| `simplerelation`   | Generic associations (org→person, domain→org, etc.)   |
| `srvdnsrelation`   | SRV record relationships (service discovery)          |

### Common Relationship Patterns

```
fqdn ──basicdnsrelation──► ipaddress       (A/AAAA record)
fqdn ──basicdnsrelation──► fqdn            (CNAME record)
fqdn ──prefdnsrelation──► fqdn             (NS delegation)
domainrecord ──simplerelation──► fqdn       (domain → FQDN)
ipaddress ──portrelation──► service         (IP → service)
ipaddress ──simplerelation──► netblock      (IP ∈ netblock)
netblock ──simplerelation──► autnumrecord   (netblock → ASN record)
autnumrecord ──simplerelation──► autonomoussystem  (record → AS)
organization ──simplerelation──► person     (org → contact)
tlscertificate ──simplerelation──► fqdn     (cert SAN → FQDN)
```

### Tags as Properties

Tags provide metadata annotations on entities and edges:

| Tag Type             | Used For                                   |
|----------------------|--------------------------------------------|
| `sourceproperty`     | Which data source discovered this asset    |
| `dnsrecordproperty`  | DNS record details (TTL, record type)      |
| `simpleproperty`     | Generic key-value metadata                 |
| `vulnproperty`       | Vulnerability information                  |
